2~4회차에는 모델을 만들었고, 5회차에는 에이전트에게 일을 시켰습니다. 오늘은 이미 만들어진 모델과 도구를 빌려 쓰는 법입니다. 무료로 쓸 수 있는 사전학습 모델, 에이전트에 도구를 연결하는 MCP, 그리고 말로 3D 부품을 만드는 Fusion 360 까지. 각 장 끝의 “따라 해 보기” 상자는 모임이 끝난 뒤 혼자 해 볼 수 있게 적어 둔 절차입니다.

메시지 1 — 학습 없이 써도, 재 보기는 해야 한다

빌려 온 모델이 내 이미지에서 얼마나 맞는지는 아무도 대신 알려 주지 않습니다. 방법은 4회차와 같습니다. 정답을 조금 만들고, 지표로 잽니다. 이미지 한두 장에서 세포나 입자 20개쯤을 손으로 그리면 충분합니다. 정답과 겹치는 정도(IoU)로 “맞았다/틀렸다”를 정하고, 정밀도·재현율·F1 을 계산합니다.

그래서 이 강의를 준비하며 실제로 재 봤습니다. 공개 데이터셋 NuInsSeg 의 사람 흑색종·편도·비장 H&E 이미지 58장(정답 핵 4,990개)에 Cellpose 4 를 학습 없이 돌리고, 정답과 겹침(IoU)이 0.5 를 넘으면 맞힌 것으로 셌습니다. 강사 노트북(RTX 5050 Laptop)에서 이미지 한 장에 1초가 안 걸렸습니다.

그림 1학습 없이 돌린 Cellpose 4 — 흑색종(위)·편도(아래), F1 이 중간쯤인 이미지
왼쪽 원본, 오른쪽 채점 결과. 초록 = 맞힌 예측, 빨강 = 정답에 없는 예측(헛것), 노랑 = 놓친 정답. 좋은 이미지만 고르지 않으려고 장기마다 F1 이 중간값인 이미지를 골랐습니다(흑색종 0.68, 편도 0.74). 이미지: NuInsSeg (Mahbod et al., 2024), CC BY 4.0.

읽는 법. 정밀도 0.83 은 “Cellpose 가 핵이라고 한 것 10개 중 8개는 진짜”, 재현율 0.65 는 “진짜 핵 10개 중 6~7개를 찾았다”는 뜻입니다. 찾은 핵의 경계는 정답과 잘 맞습니다(Dice 0.87). 학습 없이 이 정도면 출발점으로는 충분합니다. 그런데 숫자를 하나 더 쪼개 보면 이야기가 달라집니다.

작은 핵을 놓칩니다. 핵을 크기순으로 넷으로 나누면, 가장 작은 25% 는 13% 만 찾았고 가장 큰 25% 는 92% 를 찾았습니다. 이미지 가장자리에 잘린 핵을 빼도, 다른 모델(InstanSeg)로 바꿔도 같았습니다. 림프구처럼 핵이 작은 면역세포를 세는 연구라면 개수가 체계적으로 적게 나올 수 있다는 뜻입니다 — 전체 F1 하나만 보면 안 보이는 문제입니다.

손잡이로는 안 고쳐졌습니다. 3회차의 conf 슬라이더처럼 cellprob 임계값을 낮춰 “더 많이 잡아라”고 하면 오히려 나빠졌고(이웃 핵끼리 합쳐짐), 지름 설정도 효과가 없었습니다. 손잡이로 안 되는 약점이 보이면 그때가 내 데이터로 가르칠(파인튜닝) 때입니다 — Part 5 의 3단계입니다. 반대로 InstanSeg 는 이미지의 픽셀 크기를 알려 주는 것만으로 F1 0.52 → 0.73 이 됐습니다. 모델마다 꼭 알려 줘야 하는 정보가 다릅니다.

그림 2놓친 작은 핵을 열어 보면 — 노랑 = 정답, 초록 = Cellpose
점수만 보지 말고 틀린 것을 열어 보세요. 세 종류가 섞여 있습니다. ① 모델이 놓친 것 — 흐리거나 가늘고 납작한 핵. ② 정의가 다른 것 — 정답은 핵의 일부만, 모델은 주변까지 크게 그려서 겹침이 0.5 를 못 넘김. ③ 정답이 이상한 것 — 공개 데이터셋에도 같은 번호가 여기저기 흩어진 조각(약 900개 핵에서 발견)과 30 픽셀 미만 찌꺼기(256개)가 있었고, 이것들을 정리하자 F1 이 0.70 → 0.73 으로 올랐습니다. 무엇을 “핵”으로 셀지는 모델이 아니라 연구 질문이 정합니다.

4회차의 규칙이 여기도 적용됩니다. 위 표의 설정 비교는 같은 58장으로 했기 때문에 “어떤 손잡이가 듣는지 알아본 탐색”입니다. 이 중 제일 좋은 설정의 숫자를 논문에 쓰려면, 설정을 정한 뒤 처음 보는 이미지로 한 번만 다시 재야 합니다.

메시지 2 — 라이선스는 세 겹이다

3회차에서 YOLO 의 AGPL 함정을 봤습니다. 빌려 쓰는 모델은 코드 · 가중치 · 학습 데이터의 라이선스가 따로 붙습니다. 코드가 자유로워도 가중치가 비상업 전용일 수 있습니다. 논문 연구는 대개 괜찮지만, 특허·기술이전·제품에 넣을 계획이 있다면 세 겹을 모두 확인하세요.

3회차의 한 줄을 SEM 에서 다시 봅니다. 강사 노트북에서 SEM 이미지 두 종류에 Fiji 기본 방식(임계값 + watershed, 아래 따라 해 보기의 메뉴 순서 그대로)과 NP-SAM 을 학습 없이, 기본값으로 돌렸습니다.

웹 · 5분Cellpose 4 — 이미지 올리고 마스크 받기▶
  1. huggingface.co/spaces/mouseland/cellpose 를 엽니다. 로그인하라고 하면 무료 Hugging Face 계정으로 로그인합니다.
  2. Drop Image Here - or - Click to Upload 에 이미지를 올립니다. 여러 장은 Multi-file upload 로. PNG·JPG·TIF 모두 됩니다.
  3. 설정은 그대로 두고 Run CellposeSAM 을 누릅니다.
  4. Download masks (TIF)(세포마다 번호가 매겨진 마스크) 또는 Download outlines (PNG)(윤곽선 그림)으로 결과를 받습니다.
  5. 무료 GPU 시간은 하루 약 5분입니다 — 이미지 수백 장 분량입니다. 더 필요하면 아래처럼 내 PC 에 설치합니다.

내 PC 에 설치하려면 (아나콘다 프롬프트에서, 마우스로 쓰는 프로그램이 뜹니다):

conda create --name cellpose python=3.11
conda activate cellpose
python -m pip install "cellpose[gui]"
python -m cellpose        # 처음 실행할 때 모델을 자동으로 받습니다
웹 · 5분SAM 3 — 글자로 지시해서 분할하기▶
  1. aidemos.meta.com/segment-anything 를 열고 Try it now 를 누릅니다.
  2. 약관 창이 뜹니다. “개인적·비상업적 용도의 연구 데모”라는 조건입니다. 동의(Accept)합니다.
  3. Create image cutouts (SAM 3) 를 고르고 이미지를 올립니다.
  4. “worm”, “cell”, “particle” 처럼 찾을 물체를 글자로 적습니다. 해당하는 물체가 전부 칠해집니다. 잘 안 잡히면 물체를 직접 클릭해 봅니다.

업로드에 Meta 계정 로그인이 필요한지는 확인하지 못했습니다. 미발표 이미지는 올리지 마세요 — 외부 데모 서버입니다.

설치 · 20분QuPath + InstanSeg — 조직 이미지에서 핵 찾기▶
  1. qupath.github.io 에서 QuPath 0.7.0 윈도우 설치 파일(QuPath-v0.7.0-Windows.msi)을 받아 설치합니다.
  2. Extensions > Manage extensions 의 QuPath catalog 에서 Deep Java Library 와 InstanSeg 옆의 초록색 + 를 눌러 설치하고, QuPath 를 다시 시작합니다.
  3. 이미지를 연 뒤 Extensions > InstanSeg 를 엽니다. 폴더 아이콘으로 모델을 저장할 폴더를 고르고, 목록에서 brightfield_nuclei 를 골라 내려받습니다(구름 아이콘 = 아직 안 받음).
  4. Preferred device 는 CPU 로 둡니다. 느리지만 가장 안전하고, GPU 가 없어도 됩니다.
  5. 사각형 도구로 작은 영역을 그리고 Run 을 누릅니다. 처음 실행할 때 필요한 파일을 자동으로 받습니다.

brightfield_nuclei 는 헤마톡실린·DAB 염색으로 학습됐고 다른 염색에도 쓸 수 있다고 안내돼 있습니다. H&E 에서 얼마나 맞는지는 메시지 1 처럼 직접 재 보세요.

설치 · 15분Fiji — SEM 입자 크기 분포 (딥러닝 없이)▶
  1. fiji.sc 에서 Fiji 를 받아 압축을 풀고 실행합니다. SEM 이미지를 엽니다.
  2. 직선 도구로 스케일바 길이만큼 선을 긋고 Analyze > Set Scale… 에서 Known Distance 와 단위(예: nm)를 적습니다. 스케일바·글자 영역은 사각형으로 선택해 지우거나 잘라냅니다.
  3. Image > Type > 8-bit → Image > Adjust > Threshold… 에서 입자만 칠해지게 조절하고 Apply. SEM 처럼 어두운 바탕에 밝은 입자면 Dark background 를 체크합니다. 입자 대신 바탕이 통째로 잡히면 Process > Binary > Options… 에서 Black background 를 체크하고 다시 합니다 — 강사도 처음에 이 함정에 걸렸습니다.
  4. 붙은 입자를 나누려면 Process > Binary > Watershed.
  5. Analyze > Set Measurements… 에서 Area 와 Feret's Diameter 를 체크합니다.
  6. Analyze > Analyze Particles… 에서 Show: Outlines, Display results, Exclude on edges, Summarize 를 체크하고 실행합니다. 결과 창에서 File > Save As… 로 표를 저장합니다.
설치 · 20분NP-SAM — SEM 입자 분할 (딥러닝)▶

A. 윈도우 앱 (마우스로)

  1. pypi.org/project/npsam 의 안내에서 윈도우 앱을 받습니다. GPU 가 없으면 CPU 판(약 500 MB), NVIDIA GPU 가 있으면 CUDA 판(약 2.5 GB).
  2. 압축을 풀고 .exe 를 실행합니다.
  3. 이미지 열기 → 스케일 지정 → 분할 → 잘못 잘린 것 걸러내기 → 크기 표 내보내기 순서로 진행합니다. 앱 안의 버튼 이름은 공식 문서에 없어 여기 적지 않았습니다(강사는 아래 B 로 확인했습니다).

B. 파이썬 (강사 노트북에서 실제로 돌린 방법) — 아나콘다 프롬프트에서:

conda create -n npsam python=3.10
conda activate npsam
set PYTHONUTF8=1          # 한국어 윈도우에서 의존성(clip) 설치가 cp949 오류로 깨지는 것을 막습니다
pip install npsam
python
>>> from npsam import NPSAMImage
>>> img = NPSAMImage("내_SEM_이미지.png")     # 정보 막대는 미리 잘라 둡니다
>>> img.segment()                             # 처음엔 가중치를 받을지 묻습니다 → Y
>>> img.filter()                              # 걸러내기 창(슬라이더) — 강사는 창이 뜨는 환경까지만 확인
>>> img.export_all()                          # 마스크·크기 표 내보내기

가중치 다운로드가 실패하면 — NP-SAM 은 가중치를 OSF 에서 받는데, 강사 노트북에서는 그 저장소 주소를 찾지 못해 실패했습니다. 같은 파일을 공식 출처에서 받아 NP-SAM 설치 폴더(site-packages\npsam\)에 넣으면 됩니다: FastSAM 은 FastSAM-x.pt 를 FastSAM.pt 라는 이름으로, SAM ViT-H 는 Meta 의 sam_vit_h_4b8939.pth(2.5 GB) 그대로.

고급 · 40분+Tierpsy Tracker — 선충 행동 영상 분석▶

윈도우에서는 Docker 설치가 공식 권장입니다. 관리자 권한, WSL2, 여러 번의 재부팅, X 서버(VcXsrv)가 필요하고 공식 안내 기준 20~40분 걸립니다. 연구실 IT 담당자와 함께 하시길 권합니다. 설치 안내: Tierpsy 설치 문서(Docker).

  1. 설치 후 tierpsy_gui 를 실행합니다.
  2. Set Parameters 에서 Threshold, Is Light Background?, Frame per Second, Microns per Pixel, Analysis Type 을 정하고 Save Parameters 로 설정 파일(JSON)을 저장합니다.
  3. Batch Processing Multiple Files 에서 Original Videos Dir(원본 영상 폴더), Masked Videos Dir, Tracking Results Dir 를 정하고, File Pattern to Include 에 영상 파일 이름, Parameters Files 에 방금 저장한 JSON 을 넣고 실행합니다.

설치가 부담스러우면 SAM 3 웹 데모에 영상을 올리고 “worm” 으로 추적해 보는 것부터 시작해도 됩니다. 다만 선충끼리 닿으면 번호가 뒤바뀌기 쉽습니다.

채점 · 20분정답 20개로 재 보기 — 에이전트에게 맡기기▶
  1. 이미지 한두 장에서 물체 20개쯤을 손으로 칠해 정답 마스크를 만듭니다. QuPath 의 브러시 도구나 2회차에 써 본 CVAT 를 쓰면 됩니다. 정답 마스크가 함께 배포되는 공개 데이터셋이면 이 단계는 건너뜁니다.
  2. 모델 결과 마스크(예: Cellpose 의 masks TIF)와 정답 마스크를 한 폴더에 둡니다.
  3. Claude Code(또는 코드 실행이 되는 에이전트)에게 아래 문장을 붙여넣습니다.
채점 프롬프트이 폴더의 정답 마스크와 예측 마스크(둘 다 물체마다 번호가 다른 정수 라벨 이미지)를 비교해 줘. 물체끼리 IoU ≥ 0.5 이면 맞힌 것으로 짝짓고, 정밀도·재현율·F1 과 짝지은 물체들의 평균 Dice 를 계산해 줘. 정답·예측 윤곽선을 원본 위에 겹친 그림도 outputs/ 에 저장해 줘. 계산 코드는 src/ 에 남겨 줘.

이 강의 자료의 검증 예시를 만든 스크립트도 레포의 session6/tools/ 에 있습니다.

Part 3 · MCP

에이전트의 손

5회차에서 에이전트 = 모델 + 하네스라고 했습니다. MCP(Model Context Protocol)는 그 하네스에 바깥 도구를 꽂는 표준 플러그입니다. 한 번 꽂으면 에이전트가 PubMed 를 검색하고, 그림 템플릿을 찾고, 이미지 프로그램과 CAD 를 직접 조작합니다.

그림 4같은 모양의 플러그, 다른 도구
왼쪽은 인터넷에 있는 서비스(원격 커넥터 — 클릭 몇 번으로 켬), 오른쪽은 내 컴퓨터의 프로그램(로컬 MCP — 설치 필요)입니다. 에이전트 쪽은 바뀌지 않고 플러그만 늘어납니다.

① PubMed — 선충PubMed 에서 최근 2년간 예쁜꼬마선충(C. elegans)의 행동을 딥러닝으로 정량화한 논문 5편을 찾아 줘. 표로 정리해 줘: 제목, 연도, 쓴 모델, 데이터(영상 종류), 코드 공개 여부, PMID.
② bioRxiv — TMEbioRxiv 에서 최근 6개월 사이에 나온, 종양미세환경(TME) 면역세포의 공간 분포를 조직 이미지로 분석한 프리프린트를 찾아서 분석 방법별로 묶어 줘.
③ Hugging Face — SEMHugging Face 에서 주사전자현미경(SEM) 나노입자 분할에 쓸 수 있는 모델과 데이터셋을 찾아 줘. 표에 라이선스 열을 꼭 넣어 줘.
④ BioRender — 그림BioRender 에서 종양미세환경 모식도(종양세포, T세포, 대식세포, 혈관)에 쓸 아이콘과 템플릿을 찾아 줘.

Zotero MCP (커뮤니티 제작, 무료) — Zotero 데스크톱이 설치돼 있어야 하고, uv 도구가 필요합니다.

uv tool install zotero-mcp-server
zotero-mcp setup          # Claude 데스크톱 연결 설정을 자동으로 해 줍니다

napari-mcp (royerlab, 무료) — 아나콘다 프롬프트에서 (강사 노트북에서 확인한 순서):

conda create -n napari python=3.11
conda activate napari
pip install "napari[all]" napari-mcp     # napari-mcp 만 깔면 화면(Qt)이 없어 창이 안 뜹니다
napari-mcp-install install claude-desktop --persistent --dry-run   # 무엇을 바꾸는지 미리 보기
napari-mcp-install install claude-desktop --persistent             # Claude 데스크톱 설정에 등록 (자동 백업)

설치 후 Claude 데스크톱을 완전히 종료했다가 다시 켜면 도구 16개(뷰어 열기, 레이어 추가, 스크린샷, 코드 실행 등)가 나타납니다. 이 중 execute_code 와 install_packages 는 에이전트가 내 PC 에서 아무 코드나 돌리고 패키지를 설치할 수 있다는 뜻이니, 도구 호출 승인 창을 꼭 읽으세요.

시연 — 96-well plate 트레이

프롬프트 1 — 만들기Fusion 에서 단위는 mm 로 해 줘. 사용자 매개변수 clearance=0.4, wall=4, depth=8, base=3 을 만들어. ANSI/SLAS 표준 96-well plate(바닥 127.76 × 85.48 mm)를 올려놓는 트레이를 만들어 줘. 포켓은 plate 바닥에 사방 clearance 를 더한 크기, 벽 두께는 wall, 포켓 깊이는 depth, 바닥 두께는 base 로. 바깥 세로 모서리에는 2 mm 필렛, 긴 변 양쪽 벽에는 폭 20 mm 손가락 홈을 내 줘. 끝나면 바운딩 박스 크기를 알려 주고, 등각 뷰 스크린샷을 찍고, STL 로 내보내 줘.
프롬프트 2 — 고치기clearance 를 0.6 으로 바꾸고 STL 을 다시 내보내 줘. 바뀐 바운딩 박스도 알려 줘.

시연의 핵심은 두 번째 프롬프트입니다. 처음부터 치수를 매개변수로 만들게 했기 때문에, 출력해 보니 꽉 끼면 숫자 하나만 바꿔 다시 뽑습니다. 5회차의 교훈과 같습니다 — 에이전트에게 맡길 때도 바꿀 수 있는 곳을 미리 정해 두는 것이 사람의 일입니다.

★
잘 시키는 요령. ① 단위(mm)를 매번 적습니다. ② 바꿀 가능성이 있는 치수는 “사용자 매개변수로” 만들라고 합니다. ③ 한 번에 한 기능씩 — 4회차의 “한 번에 하나만”과 같습니다. ④ 에이전트가 고치기 전에 저장해 둡니다. ⑤ 한 단계에 수십 초씩 걸립니다. 기다리세요.

설정 · 10분Fusion 과 Claude 데스크톱 연결하기▶
  1. Fusion 을 최신 버전으로 업데이트하고 엽니다. Preferences > General > API 에서 Fusion MCP Server 를 체크하고, 옆의 Fusion MCP Server Port 번호(기본 27182)를 적어 둡니다. Apply 또는 OK 를 눌러야 저장됩니다.
  2. Claude 데스크톱 앱에서 Customize > Connectors > + 를 누르고 “Fusion” 을 검색해 Autodesk Fusion 옆 + → Install.
  3. Enabled 를 켜고 Configure 에서 포트가 1단계의 번호와 같은지 확인합니다.
  4. Claude 데스크톱을 완전히 종료했다가 다시 켭니다(창만 닫으면 남아 있을 수 있습니다 — 작업 관리자에서 Claude 를 끝냅니다).
  5. Fusion 에서 새 설계 문서를 연 상태로, Claude 에게 “Fusion 에서 10 mm 정육면체를 만들어 줘”라고 시험합니다. 되면 위의 프롬프트 1·2 로 넘어갑니다.

연결이 안 될 때 — 포트 충돌. 다른 프로그램이 같은 포트를 쓰고 있을 수 있습니다(예: 일부 PC 에서는 MATLAB 의 서비스가 27182 를 씁니다). 아나콘다 프롬프트나 명령 프롬프트에서 netstat -ano | findstr 27182 로 확인하고, 이미 쓰이고 있으면 Fusion 의 포트를 비어 있는 번호(예: 27183)로 바꾼 뒤 Configure 의 포트도 같게 맞추고 두 프로그램을 모두 다시 시작합니다.
