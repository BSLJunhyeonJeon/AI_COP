# TASK — 오늘의 과제: 초파리 전뇌 시뮬레이션을 4단계로 만든다

목표: 초파리(Drosophila) 뇌 전체(뉴런 138,639개, 연결 2,700,513개)를 LIF 뉴런으로 시뮬레이션하고, 다가오는 물체를 피하는 도망 반사(looming → LPLC2 → 거대섬유 GF → 점프)로 공룡 점프 게임을 하게 한다.

규칙은 `AGENTS.md`, 수식·파라미터·출력 규격은 `docs/MODEL_SPEC.md`, 데이터는 `docs/DATA.md`. 이 문서는 "무엇을, 어떤 순서로, 언제 통과인가"만 적는다.

각 단계가 끝나면 반드시 `python tests/verify.py --stage N` 을 실행하고, PASS 일 때만 다음 단계로 간다. 예상 시간은 합계 60분이다.

## ① 뉴런 1개 — LIF 가 어떻게 발화하는가 (10분)

만들 것: `src/step1_neuron.py`

할 일: MODEL_SPEC §2 의 이산화 식으로 LIF 뉴런 하나를 구현한다. 상수 입력 I_ext = 0, 5, 7, 8, 10, 15, 20, 30 mV 각각에 대해 1000 ms 를 돌려 스파이크 수와 발화율을 재고, 해석해와 나란히 CSV 로 저장한다. v(t) 그림도 저장한다.

산출물: `outputs/01_trace.png`, `outputs/01_fi_curve.csv`, `outputs/01_summary.json` (규격은 MODEL_SPEC §5-①)

통과 조건:
- I_ext ≤ 7 mV 에서 스파이크 0 (임계값 − 휴지 = 7 mV 라 7 mV 로는 영원히 못 닿는다)
- I_ext 가 커질수록 발화율이 줄지 않는다(단조)
- I_ext ≥ 10 mV 에서 측정 발화율이 해석해의 ±5 % 안
- 발화율 < 1000 / 2.2 ≈ 454 Hz (불응기 때문에 이보다 빠를 수 없다)

힌트: 이 단계에는 시냅스도 지연도 없다. g = 0 으로 두고 v 갱신 식과 불응기만 정확히 구현하면 된다. 여기서 만든 갱신 식을 ②③④에서 그대로 재사용한다(`src/lif.py` 같은 공용 모듈을 만들어도 된다). 단, 단계마다 주 스크립트는 위에 적힌 이름 하나이고, 그 파일 하나를 실행하면 그 단계의 산출물이 전부 나와야 한다(GIF 만 따로 만드는 보조 스크립트 같은 분리는 안 된다).

## ② 3뉴런 반사궁 — 흥분과 억제의 부호 (10분)

만들 것: `src/step2_reflex.py`

할 일: 뉴런 4개(V 시각, I 억제, G 거대섬유, J 점프 운동)를 MODEL_SPEC §5-② 의 연결로 잇는다. V 를 150 Hz 포아송으로 500 ms 자극했을 때 J 가 발화하는지, 억제 뉴런 I 를 같이 자극하면 J 가 어떻게 되는지 두 조건을 돌린다. 여기서 시냅스 지연(1.8 ms)과 지연 큐를 처음 구현한다.

산출물: `outputs/02_reflex.png`, `outputs/02_summary.json`

통과 조건:
- 억제 꺼짐: J 스파이크 ≥ 1
- 억제 켜짐: J 스파이크 수가 억제 꺼짐의 20 % 이하 (참고값: 레퍼런스에서 꺼짐 28개, 켜짐 0개)
- 두 조건 모두 V 스파이크 수가 0 이 아니다(자극이 실제로 들어갔다)

힌트: 자극 뉴런은 "스스로 발화"한다 — 막전위와 무관하게 난수로 스파이크를 만들고, 그 스파이크를 지연 큐에 넣는다. 지연은 18 스텝(1.8 ms / 0.1 ms)이다.

## ③ 전뇌 장착 — 같은 식, 138,639개 뉴런 (20분)

만들 것: `src/step3_brain.py`

할 일: `data/connections.parquet` 로 희소 가중치 행렬 W 를 만들고(MODEL_SPEC §3), `data/groups.json` 의 `LPLC2_L` ∪ `LPLC2_R` 을 150 Hz 로 1000 ms 자극한다. 무자극 1000 ms 도 돌려 대조한다. 모든 뉴런의 스파이크 수를 세고, 특히 `GF_L`, `GF_R`(거대섬유)의 발화율을 기록한다.

산출물: `outputs/03_raster.png`, `outputs/03_rates.csv`, `outputs/03_summary.json`

통과 조건:
- 자극 조건에서 GF_L 과 GF_R 발화율 ≥ 50 Hz (참고값: 레퍼런스에서 GF_L 264 Hz, GF_R 349 Hz, 발화 뉴런 1,519개, 총 스파이크 94,695개, 첫 GF 스파이크 약 6 ms. 난수를 뽑는 순서가 다르면 ±수 % 달라지는 것이 정상이다)
- 무자극 조건에서 GF 발화율 = 0 Hz, 발화 뉴런 수 = 0 (입력이 없으면 이 모델은 완전히 조용하다)
- `n_neurons` = 138639, `n_connections` = 2700513
- `wall_seconds` 기록

힌트: 스텝마다 발화한 뉴런은 많아야 수천 개다. `W[idx].sum(axis=0)` 처럼 발화한 행만 더한다. 밀집 행렬(138,639 × 138,639)을 만들면 메모리가 터진다. 1000 ms = 10,000 스텝이고, 노트북 CPU 에서 수십 초~수 분이 정상이다(레퍼런스: 2코어 CPU 에서 자극 1 s 에 16 s, 무자극 1 s 에 8 s). 진행 상황을 1000 스텝마다 출력하면 멈춘 게 아닌지 알 수 있다.

## ④ 공룡 게임 — 반사로 점프하기 (20분)

만들 것: `src/step4_dino.py`

할 일: MODEL_SPEC §4 의 규칙대로 에피소드(속도 5단계 × 선인장 3개 = 15개)를 돌린다. 에피소드마다 선인장의 각크기 θ(t) 를 계산해 θ ≥ θ_on 인 동안 LPLC2 를 자극하고, GF 첫 스파이크로 점프 시각을 정해 통과/충돌을 판정한다. 속도별 통과율 그래프와 GIF 두 장면을 만든다.

산출물: `outputs/04_dino.gif`, `outputs/04_speed_vs_pass.png`, `outputs/04_log.csv`, `outputs/04_summary.json`

통과 조건:
- 15개 에피소드가 모두 `04_log.csv` 에 있다
- 기본 속도(k = 3)의 통과율 ≥ 0.8
- 최고 속도(k = 5)에서 실패 ≥ 1 (반사 지연 때문에 어느 속도부터는 늦는다)
- `latency_ms` 가 기록된 에피소드가 1개 이상이고 모두 0 보다 크다
- GIF 가 두 에피소드의 장면을 실제로 담고 있다: 프레임 30장 이상, 640×360 이상, 빈 프레임 없음, 프레임 간에 움직임이 있음 (MODEL_SPEC §5-④)
- 모든 PNG 는 400×300 이상이고 빈 그림이 아니다

힌트: ③에서 만든 시뮬레이션 함수에 "시각 t 에 자극할 그룹"만 바꿔 넣으면 된다. 에피소드마다 뇌를 휴지 상태로 초기화하고 시드를 1000·k + j 로 둔다. 통과율이 낮아도 상수를 만지지 않는다 — 그래프는 나온 대로 둔다.

시간: 15개 에피소드의 시뮬레이션 길이 합은 약 5.3 초(신경 시간)이고, ③의 속도라면 wall time 1~3분이다. 명령 실행 도구의 시간 제한(흔히 2분)에 걸릴 수 있으니 AGENTS.md 규칙 14 대로 제한을 늘리거나 백그라운드로 돌린다. 에피소드가 하나 끝날 때마다 결과를 `outputs/04_log.csv` 에 이어 쓰고, 다시 실행하면 이미 있는 에피소드는 건너뛰게 만들면 끊겨도 이어서 간다.
