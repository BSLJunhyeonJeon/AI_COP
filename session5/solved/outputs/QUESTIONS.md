# QUESTIONS — 스펙에서 불명확했던 부분과 내가 택한 해석

구현은 아래 해석대로 했고 verify 는 전부 PASS 다. 다른 해석을 원하면 알려 달라.

1. **④ 착지 후 재점프** — MODEL_SPEC §4 규칙 3 은 "공중일 때 나오는 GF 스파이크는 무시"라고만 하고, 착지한 뒤의 GF 스파이크는 언급이 없다.
   LPLC2 자극이 t_c 까지 계속되므로 GF 는 착지 뒤에도 계속 발화한다(~300 Hz). 재점프를 허용하면 k = 1(느린 선인장)도 통과해 버려
   "느린 물체엔 너무 일찍 뛴다(too_early)" 는 메시지와 어긋난다. → **에피소드당 점프 1회, 첫 GF 스파이크만 사용** 으로 해석했다.
2. **④ 접촉 후의 θ(t)** — d(t) ≤ 0 이면 θ = 2·atan(h/(2d)) 가 정의되지 않거나 음수다. → d ≤ 0 은 접촉 상태로 보고 θ = 180° 로 두어
   t_c 이후 t_c + 50 ms 까지도 자극이 켜진 채로 뒀다. 통과/충돌 판정은 t_c 에서 끝나므로 결과에는 영향이 없다.
3. **자극 뉴런의 막전위 발화** — "막전위와 무관하게 스스로 발화" 를, 자극이 켜진 스텝에서는 **포아송 추첨 결과만 그 뉴런의 스파이크로 삼는다**
   (막전위로 넘은 것은 무시, 스파이크 시 v 리셋·불응 적용)로 해석했다. LPLC2 평균 발화율 149.8 Hz 로 150 Hz 와 맞는다.
4. **③ 래스터의 "발화율 상위 20개"** — 자극 뉴런과 GF 를 뺀 나머지 중 상위 20개로 그렸다.
5. **`wall_seconds` 와 이어서 실행** — 규칙 12 의 "이어서 가기"를 하면 두 번째 실행의 wall 은 몇 초뿐이다. `0N_summary.json` 의 `wall_seconds` 는
   그 실행의 wall 로 두고, ③은 `sim_wall_seconds`, ④는 `wall_seconds_episodes_total` 에 실제 시뮬레이션 시간을 따로 남겼다.
6. **outputs/ 의 보조 파일** — 이어서 실행하기 위한 중간 결과(`03_spikes_*.npz`, `04_episodes/*.npz`)와 규칙 14 가 권한 실행 로그
   (`03_run.log`, `04_run.log`)를 outputs/ 에 뒀다. 규칙 7(산출물은 src 가 만든다)과 충돌하지 않는지 확인 바란다(로그는 셸 리다이렉트로 만들어진다).
